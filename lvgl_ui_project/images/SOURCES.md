# Asset sources

- `icons/src/`: Lucide icons (lucide-static 1.72.0, ISC license, see `LICENSE.txt`). The SVGs use a black stroke instead of `currentColor`.
- `logos/lvgl_logo_white.png`: the official LVGL logo, white version for dark backgrounds.
- `logos/winstar_logo_white.png`: the Winstar logo, used with Winstar's permission; the text is white for dark backgrounds.
- `splash/splash_s.png`: splash background, 800x480, generated with the OpenAI image API. It has no text or logos.
- `../fonts/inter/`: Inter 4.1 (SIL Open Font License, see `LICENSE.txt`).
